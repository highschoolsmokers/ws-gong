# ws-gong

Personal site of W.S. Gong: Next.js 16 (App Router), React 19, Tailwind 4, on
Vercel. [SPEC.md](SPEC.md) is the full specification.

```bash
pnpm install
pnpm dev            # http://localhost:3000
pnpm sync           # copy, links, résumé and CV from resumes-cvs (SPEC §14)
vercel deploy --prod
```
